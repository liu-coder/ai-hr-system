# Workflow Automator

A skill for designing and automating workflows to improve efficiency.

## When to Use
- When designing new workflows or processes
- When automating repetitive tasks
- When optimizing existing workflows
- When creating workflow diagrams and documentation
- When implementing workflow automation solutions

## How to Use
1. **Analyze process**: Understand the current workflow or process
2. **Identify automation opportunities**: Find tasks that can be automated
3. **Design workflow**: Create a structured workflow diagram
4. **Implement automation**: Develop and deploy automation solutions
5. **Monitor and optimize**: Track performance and make improvements

## Output Format
```markdown
# Workflow Automation Plan

## Overview
- **Process**: [Process name]
- **Current State**: [Description of current process]
- **Goal**: [Automation goal]

## Workflow Diagram
[Workflow diagram or description]

## Automation Opportunities

### Opportunity 1: [Task name]
- **Description**: [Task description]
- **Current process**: [How it's done now]
- **Automation approach**: [How to automate]
- **Tools needed**: [Required tools/technologies]
- **Benefits**: [Expected benefits]

## Implementation Plan
1. [Step 1]
2. [Step 2]
3. [Step 3]

## Expected Outcomes
- [Outcome 1]
- [Outcome 2]
- [Outcome 3]

## Monitoring and Optimization
- [Monitoring approach]
- [Optimization strategies]
```

## Example

**Input**: "Automate the employee onboarding process"

**Output**:
```markdown
# Workflow Automation Plan

## Overview
- **Process**: Employee Onboarding
- **Current State**: Manual process with multiple handoffs and paper forms
- **Goal**: Streamline onboarding to reduce time and errors

## Workflow Diagram
```
1. HR receives new hire information
2. HR creates employee record in HR system
3. IT sets up computer and access
4. Facilities arranges workspace
5. Manager provides training
6. HR collects and processes paperwork
```

## Automation Opportunities

### Opportunity 1: Employee Record Creation
- **Description**: Creating employee records in HR system
- **Current process**: Manual data entry from paper forms
- **Automation approach**: Form automation with data validation
- **Tools needed**: HRIS API integration, form builder
- **Benefits**: Reduce data entry errors, save 30 minutes per employee

### Opportunity 2: IT Setup
- **Description**: Setting up computer and system access
- **Current process**: Manual request via email
- **Automation approach**: Service catalog with automated provisioning
- **Tools needed**: IT service management tool, scripting
- **Benefits**: Reduce setup time from 2 days to 4 hours

### Opportunity 3: Paperwork Collection
- **Description**: Collecting and processing onboarding paperwork
- **Current process**: Manual collection and filing
- **Automation approach**: Digital document management
- **Tools needed**: Document management system, e-signature
- **Benefits**: Eliminate paper, reduce processing time by 50%

## Implementation Plan
1. Implement form automation for employee data collection
2. Set up IT service catalog with automated provisioning
3. Deploy digital document management system
4. Integrate systems for seamless data flow
5. Train stakeholders on new process

## Expected Outcomes
- Reduce onboarding time from 1 week to 2 days
- Eliminate 90% of manual data entry
- Improve new hire satisfaction
- Reduce compliance risks

## Monitoring and Optimization
- Track onboarding completion time and errors
- Collect feedback from new hires and stakeholders
- Identify additional automation opportunities
- Regularly review and update workflow
```

## Supported Workflows
- Employee onboarding/offboarding
- IT service requests
- Approval processes
- Data processing workflows
- Customer onboarding
- Content publishing
- Financial processes
- Project management

## Automation Tools
- Workflow engines (e.g., Camunda, Activiti)
- Low-code platforms (e.g., Zapier, Microsoft Power Automate)
- Scripting and automation (e.g., Python, PowerShell)
- API integrations
- Robotic Process Automation (RPA)

## Best Practices
- Start with small, high-impact workflows
- Involve stakeholders in design
- Document workflows thoroughly
- Test automation before full deployment
- Monitor performance and iterate
- Ensure compliance with regulations

## Integration
This skill can help integrate with various workflow automation platforms and tools to implement end-to-end solutions.
